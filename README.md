# console_app

## chrome_version_browser

A console app that browses live Chrome for Testing versions (milestone 115+): pick a version,
choose Chrome or ChromeDriver, pick a platform, and get the direct download URL. Runs from
Python source or as a standalone Windows `.exe` built with PyInstaller.

See [chrome_version_browser/README.md](chrome_version_browser/README.md) for how to run and build it.
